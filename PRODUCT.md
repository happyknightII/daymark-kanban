# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
React + Vite, confirmed by the user.

## Users
One person organizing personal tasks across daily life, home, work, and relationships.

## Product Purpose
Daymark is a lightweight personal kanban board that helps its owner capture loose tasks, choose a manageable set for today, and see work move to done. Success means opening the board and knowing what to focus on without configuring a project system first.

## Positioning
A personal daily board with a dedicated focus mode and device-local storage, rather than a team project tracker.

## Operating Context
Used for everyday planning and quick capture. The first-run board demonstrates a mix of personal tasks and can be edited or cleared.

## Capabilities and Constraints
The first version supports task capture, four default stages, project swimlanes, date-based roadmapping with milestones, drag and drop, search, completion, a focus view, and browser local storage. Projects and tasks can be created locally. Single-user and offline-first. Cloud sync, accounts, collaboration, and custom-column editing are open decisions.

## Evidence on Hand
No customer research, testimonials, or external product evidence was supplied. Starter tasks are illustrative examples.

## Product Principles
- Keep capture quick.
- Make the next useful action easy to see.
- Support personal contexts without requiring a project hierarchy.
- Keep personal data on the device by default.
