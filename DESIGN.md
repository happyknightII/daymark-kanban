# Daymark visual direction

Daymark is a calm personal planning tool. The UI uses a warm off-white canvas, muted botanical greens, quiet color tags, and compact sans-serif typography. The board is the primary surface; focus mode removes board-level detail and gives one task room to breathe.

## Interface rules

- Keep the board visible and scannable without a dashboard of metrics.
- Use color to distinguish task context and stage, not as decoration.
- Keep quick capture close to each column and in the shared top bar.
- Let focus mode contain one prominent task and a clear way back.
- Keep layouts usable at narrow mobile widths.
